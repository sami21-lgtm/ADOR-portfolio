# RADOR Designs — Portfolio Website

A premium, high-performance personal portfolio website built for **RADOR Designs**, showcasing expertise in graphic design, visual storytelling, sports media graphics, and cinematic posters.

⚡ **Live Demo:** [Deploy your GitHub Pages link here]

---

## ✨ Features

- **Premium UI/UX:** Dark-themed aesthetic featuring neon highlights (`#00ff88`) tailored for creative professionals.
- **Dynamic Filter System:** Seamlessly sort projects across various design categories (Football, Cricket, Automotive, Film, Music, Festival, Logo) without refreshing the page.
- **Interactive Lightbox:** Full-screen asset preview with smooth controls (Next/Prev buttons and keyboard arrow key navigation).
- **Smooth Cursor Tracking:** Custom mouse follower effects that interact dynamically with links and hover elements.
- **Scroll Animations:** Fluid reveal-on-scroll animations built on premium cubic-bezier curves.
- **Responsive Layout:** Fully optimized for mobile, tablet, and desktop viewports using utility-first styling.

---

## 🛠️ Built With

- **HTML5:** Semantic architecture and core document setup.
- **Tailwind CSS:** Modern configuration, custom color extension, dynamic layout utilities, and typography tracking.
- **Vanilla JavaScript:** Native interactive components, gallery state handlers, scroll events, and custom cursor animations.
- **Iconify:** Lightweight and pixel-perfect svg micro-icon system.
- **Google Fonts:** Inter typeface injection for maximum text readability.
